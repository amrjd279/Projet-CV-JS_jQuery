## 🎯 Aperçu

Ce projet est un **CV interactif et moderne** développé pour présenter mon parcours, mes compétences et mes projets en tant qu'étudiant en informatique spécialisé en développement d'applications et conception web.

Le site offre une expérience utilisateur optimale avec :
- Un design responsive (mobile, tablette, desktop)
- Un mode sombre/clair personnalisable
- Une version optimisée pour l'impression (format A4)
- Des animations fluides et professionnelles

---

## ✨ Fonctionnalités

### 🎨 Interface Utilisateur
- **Design Responsive** : Adaptation automatique à tous les écrans
- **Mode Sombre/Clair** : Basculement dynamique avec persistance localStorage
- **Typography Animée** : Effet machine à écrire pour le nom (Typed.js)
- **Barre de Progression** : Indicateur de scroll en temps réel

### 🖨️ Impression
- **Format A4 optimisé** : Mise en page compacte sur une page
- **Styles dédiés** : @media print pour une impression professionnelle
- **Éléments masqués** : Les boutons d'action sont exclus de l'impression

### 🎬 Animations
- **Scroll Animations** : Apparition progressive des sections (Intersection Observer)
- **Hover Effects** : Interactions fluides sur les compétences et projets
- **Transitions** : Effets CSS optimisés pour une navigation agréable

### 📱 Navigation
- **Menu Latéral** : Informations de contact, compétences, certifications
- **Sections Organisées** : Profil, Compétences, Formations, Expériences, Projets
- **Liens Externes** : LinkedIn, GitHub accessibles directement

## 🛠️ Technologies utilisées

### Frontend
- **HTML5** : Structure sémantique et accessible
- **CSS3** : Variables CSS, Flexbox, Grid, Animations
- **JavaScript (ES6+)** : Fonctionnalités interactives

### Bibliothèques & Frameworks
- **Typed.js** : Animation de texte dynamique
- **Font Awesome 6.0** : Icônes vectorielles
- **Google Fonts** : Typographie moderne (Segoe UI, Roboto)

### Outils
- **Git & GitHub** : Versionning et hébergement
- **VS Code** : Éditeur de code
- **Chrome DevTools** : Debugging et optimisation
