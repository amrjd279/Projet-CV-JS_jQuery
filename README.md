# CV Interactif - Amr Jaddad

Ce dépôt contient le code source de mon curriculum vitae interactif. L'objectif est de présenter mon parcours académique, mes compétences techniques et mes projets de manière moderne et accessible.

## 🚀 Aperçu
- **Design Moderne** : Interface épurée avec un mode sombre (Dark Mode) intégré.
- **Responsive** : Adapté aux écrans mobiles, tablettes et ordinateurs.
- **Optimisé pour l'impression** : CSS spécifique pour générer un PDF propre via la fonction d'impression du navigateur.
- **Animations fluides** : Utilisation de l'*Intersection Observer API* pour des effets d'apparition au défilement.

## 🛠️ Technologies utilisées
* **HTML5** : Structure sémantique.
* **CSS3** : Variables CSS, Flexbox, Grid et Media Queries.
* **JavaScript (Vanilla)** : Gestion du thème et animations.
* **FontAwesome** : Bibliothèque d'icônes.
